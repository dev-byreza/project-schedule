Pengaturan API Google Calendar

Langkah Setup Cepat:
  1. Buka Google Cloud Console & buat Project baru.
  2. Aktifkan Google Calendar API.
  3. Di menu OAuth consent screen, atur user type Internal/External.
  4. Di menu Credentials, buat OAuth Client ID (Web application) & API Key.
  5. Tambahkan http://localhost atau URI host Anda ke daftar authorized JavaScript origins.
